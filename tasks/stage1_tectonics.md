# 阶段 1 · 构造演化与多种子筛选

> 前置条件：阶段 0 已由用户确认"通过"。先读 `CLAUDE.md`、`PROGRESS.md`、`docs/vision.md`、`docs/tectonics_survey.md`。
> 目标：在低分辨率下，从 300 Ma 正向演化到 0 Ma，产出**大陆格局、山系骨架、岩性分布和构造历史**；批量生成多个种子，筛选出 3–5 个候选世界交给用户挑选。

---

## 核心思想

- **大尺度复杂性来自构造。** 意大利、希腊、阿拉伯、印度这类大半岛，红海、爱琴海这类海湾与多岛海，日本、印尼这类群岛，都是构造过程的直接产物。所以海岸复杂度在本阶段就必须在**大尺度上（50–200 km）**达到地球水平。更小尺度的峡湾、溺谷要等阶段 2–3。
- **用"情景族"提高命中率。** 纯随机的初始条件很难恰好演化出"相连但破碎的超级大陆 + 残留洋盆内海"。因此生成器应按**情景族**组织：先定义演化剧本的大框架，再在框架内随机化。

### 推荐的默认情景族（可提出更好的方案）

1. **300 Ma**：若干大陆块分散分布，之间隔着几个洋盆。
2. **300–100 Ma**：大陆块逐步汇聚、碰撞，形成多条造山带；其中一个洋盆没有完全闭合，成为**残留洋盆**（未来的主内海，类似特提斯洋）。
3. **100–0 Ma**：超级大陆边缘与内部开始局部裂解：裂谷、裂谷海、弧后伸展多岛海、微大陆裂离。这让大陆**变碎但仍相连**，类似今天的亚非欧大陆。
4. 全程：热点轨迹、大火成岩省事件、海平面升降。
5. 北端有大陆块漂移到高纬；另有一块大陆漂移到极地，成为极地大陆。

参照：地球的真实历史就是"汇聚成盘古 → 裂解"，而亚非欧大陆正是盘古大陆裂解后、又与印度和阿拉伯重新碰撞的结果。

## 工作单元

### 1.1 方法验证（spike）与选型

- 基于 `docs/tectonics_survey.md`，挑 **2 种**方案在极低分辨率下各实现一个最小原型（例如 2–3 个板块，演化 100 Ma）。候选方向：
  - Cortial 等人 *Procedural Tectonic Planets* 式的程序化构造；
  - pyGPlates 管理板块运动学 + 自写规则处理地壳相互作用的混合方案。
- 用图比较：大陆形状、造山带位置、海岸形态是否"像构造产物"。
- **把对比图和你的建议交给用户，由用户选定方案**（停在这里等确认）。

### 1.2 构造模拟核心

在选定方案上实现：

- **球面网格**：处理经度 ±180° 接缝与极区，无裂缝。
- **板块**：稳定 ID、欧拉极旋转、边界类型（扩张、俯冲、碰撞、转换）随时间更新。
- **地壳属性**（每个网格点）：地壳类型、年龄、厚度、高程、**岩性**、所属板块、形成事件。
- **岩性分类**（至少）：洋壳玄武岩、古老地盾、沉积盖层（泥岩）、**石英砂岩**、**陆相红层**、**碳酸盐台地**、**蒸发岩（盐层）**、火山弧岩、溢流玄武岩、造山带变质核心、花岗岩基。
  - 碳酸盐台地：在温暖浅海（大致纬度 < 30° 的大陆架与陆表海）中积累。这是喀斯特峰林、海上峰林、蓝洞的前提。
  - 石英砂岩：大陆盆地或滨海沉积。这是平顶山、砂岩峰林的前提。
  - 陆相红层：干热气候下的内陆盆地沉积。这是丹霞的前提。
  - 蒸发岩：干旱的封闭或半封闭海盆（例如裂谷早期、残留洋盆收缩期）。这是盐丘、盐冰川的前提。
  - 花岗岩基：俯冲弧和碰撞带深部，经剥蚀出露。这是花岗岩峰丛的前提。
  - 完整的原型—岩性对应关系见 `docs/archetype_library.md`。
- **过程**：
  - 洋中脊扩张与洋壳年龄，水深按年龄—水深关系；
  - 俯冲：海沟、火山弧，**俯冲后撤与弧后伸展**（爱琴海、日本海式多岛海的来源）；
  - 大陆碰撞：地壳增厚、造山带、高原；
  - 大陆裂谷与裂解：裂谷、裂谷海、**微大陆裂离**；
  - 热点轨迹、大火成岩省、超级火山（破火山口）；
  - **撞击事件**：按尺寸—频率分布随机生成，按缩放律决定坑的大小与形态，之后随侵蚀和板块运动逐渐被破坏或掩埋（见原型库第 6 节）；
  - 走滑断层与拉分盆地；
  - 简单地壳均衡（高程与地壳厚度相关）；
  - **全球海平面变化曲线**：高海平面期淹没大陆架形成陆表海，这是"深入内陆的海湾"的来源之一。
- 本阶段的高程是**构造尺度**的。可以加简单的坡面扩散作为侵蚀的粗略代理，但不做河流侵蚀。
- 噪声只能用于低于网格分辨率的细节，并须服从构造走向。

### 1.3 历史记录

- 每 1 Ma 保存一帧（压缩存储），记录构造事件日志（碰撞、裂解、海峡开合、大火成岩省等），每个事件有时间、位置、涉及的板块 ID。
- **为矿产资源保存必要的历史**：初始陆块的继承年龄与属性、古纬度历史、俯冲弧岩浆活动时段、蛇绿岩推覆、碳酸岩、沉积盆地类型与埋藏历史等。完整清单见 `docs/mineral_resources.md` 第 3 节。**这些数据现在不存，以后无法补算。**
- 可选：输出构造类矿床的初步成矿远景图。
- 输出关键年代的古地理图：300、250、200、150、100、50、0 Ma。

### 1.4 批量生成、评分、筛选

- 单个种子在台式机 CPU 上的低分辨率运行时间目标：**几分钟量级**。记录实际耗时与内存峰值。
- 批量运行 30–100 个种子（数量按实际耗时决定）。
- 按 `quality_metrics.md` 第 E 节淘汰、评分、输出**联系表**。
- 前 5–8 名生成完整标准图组。

### 1.5 评审与用户挑选

- `world-reviewer` 评审前 5–8 名。
- 向用户汇报，**由用户挑选 3–5 个候选世界**带入阶段 2。
- 如果所有种子都不令人满意，回到 1.2 调整过程或情景族，不要降低标准。

## 验收

- [ ] 方法选型经用户确认
- [ ] 单元测试：球面接缝无裂缝；板块 ID 跨年代稳定；无瞬移；面积近似守恒；水深—年龄关系正确
- [ ] 合成测试：一个两板块的"裂谷 → 洋盆扩张"和一个"碰撞 → 造山"示例，结果符合预期
- [ ] 候选世界满足 A 层硬约束
- [ ] 候选世界的 B1 海岸复杂度指标在 **r = 100、200 km 尺度**上落在地球范围内（更小尺度留给阶段 2–3）
- [ ] 距海距离分布不比地球亚非欧大陆更"内陆化"（干旱风险代理）
- [ ] 能识别出构造类奇景原型（见原型库第 1 节），并在候选世界中出现多种
- [ ] 评审无未处理的严重问题
- [ ] 用户挑选出候选世界，并在 `PROGRESS.md` 写下"通过"
