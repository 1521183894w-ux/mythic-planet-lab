# 阶段 5 · 三维地球仪与交互界面（大纲）

> **本文件是大纲。** 进入本阶段前，主会话应细化成完整任务书，交用户确认后再开工。

## 目标

把已有的科学数据放进一个美观、流畅的本地三维地球仪，支持点击查询、图层切换、地质时间轴和地球对照模式。

## 主要内容

1. **技术选型（spike）**：CesiumJS（离线部署、自定义地形瓦片）与 Three.js（球面分块 LOD）各做最小原型，**在台式机的 GT 1030 上实测帧率和显存**，选其一。不得同时维护两套渲染器。不使用需要登录的在线地球底图。
2. **前后端**：前端建议 TypeScript + React + Vite；后端 FastAPI 提供数据查询与任务管理。全部本地运行。
3. **地球仪**：旋转、缩放、惯性、经纬网、比例尺、拾取；地形瓦片按相机高度分级加载；极区与经度接缝无裂缝。
4. **图层**：高程、阴影、岩性、板块、洋壳年龄、温度、降水、风、洋流、河网、生态、冰川、潮差、矿产远景与代表性矿床等，每层带图例、单位和 `method_class` 标签。
5. **点击信息面板**：经纬度、高程/水深、地貌类型与成因链、岩性、流域、气候、生态、奇景、科学可信度；**典型地貌图片位置**显示"尚未添加该区域典型地貌图片"，支持导入本地图片及其元数据（标题、作者、来源、许可、日期）。没有可靠信息时显示"待模拟/待核实"。
6. **地质时间轴**：300–0 Ma 拖动、播放、跳转事件；插值帧醒目标注"插值显示，非独立数值结果"。
7. **地球对照模式**：用真实地球数据（ETOPO、Natural Earth）显示，同一套工具和指标对比。
8. **状态提示**：明确显示"视觉预览已更新 / 气候仍为旧数据 / 全部图层已重算"。
9. 把阶段 4 的 2D 编辑功能接入三维界面。

## 验收要点

- 台式机（GT 1030）上流畅可用，实测帧率与内存记录在案。
- 两台电脑都能用脚本启动。
- 点击任意位置都能得到与数据一致的信息。
- 用户实际操作后确认。
