# 阶段 4 · 选定主世界、锚点与编辑（大纲）

> **本文件是大纲。** 进入本阶段前，主会话应根据前面阶段的实际经验细化，交用户确认后再开工。

## 目标

用户从候选中选定**主世界**；在此基础上放置"必须存在的奇景"、做局部地理调整，并让修改能正确传导到所有相关图层。

## 主要内容

1. **主世界选定**：候选世界的全套图组并排对比，用户选择。选定的主世界数据单独归档（大文件的同步方式事先与用户商定）。
2. **编辑的后端机制**（先做后端，再做简单界面）：
   - 每次编辑保存为补丁，可撤销、重做、建立分支、比较方案。
   - 编辑分两类：`edit_constraint`（尽量反向调整构造或过程原因，再重算）与 `state_override`（直接修改结果，标注"待地质解释"）。
   - **图层依赖图**：每个图层有 `dirty / recomputing / verified / conflict` 状态。改海峡会影响海洋、潮汐、气候，不能承诺"只重算局部"。
   - 先出低分辨率预览和差异统计，用户确认后再做高精度重算。
3. **锚点**：圣山、峡谷、巨湖、特殊高地、岛屿、**"神怒"共振海湾**等。锁定后，重算不得悄悄删改。每个锚点登记成因解释、约束强度和 `method_class`。
4. **奇景补齐**：对照原型库，把过程没有自然产出、但用户想要的原型，以锚点形式放置，并给出成因。
5. **简单编辑界面**：在 2D 地图上完成（三维界面在阶段 5）。笔刷类型：海岸抬升/下沉、局部隆升/削低、海峡开合与深度、岛屿、河口偏好。
6. **矿产**：为主世界抽样生成代表性矿床；用户可登记幻想矿物（见 `docs/mineral_resources.md` 第 4 节）。
7. **"神怒"海湾的设计与验证**：调整海湾长度、水深、开口形状，用潮汐模型验证共振，输出凶月事件的历法。

## 验收要点

- 修改海峡后，海洋、潮汐、气候相关图层被正确标为过期，重算后恢复。
- 锁定的锚点在任何重算后都保持不变。
- 保存与重新加载结果一致；取消任务不会损坏上一次结果。
- 评审：编辑后的世界仍然像真星球，人工修改处与周围地形自然衔接。
- 用户确认。
