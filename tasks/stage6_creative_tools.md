# 阶段 6 · 创作工具与导出（大纲）

> **本文件是大纲。** 进入本阶段前，主会话应细化成完整任务书，交用户确认后再开工。

## 目标

把科学行星变成世界观创作的长期工具：注记、探索视图、天象历法、出版级导出。

## 主要内容

1. **世界观注记层**：地名、区域说明、历史事件、圣地、遗迹、航路等。与科学数据**分层存储**，故事标注不得污染科学字段。（种族与文明的"入住"在此阶段之后另行规划。）
2. **两种视图**：真实科学地图 / 文明认知地图（已探索、传说、未知区域）。"未知"只对设定中的文明而言，模拟器内部地理始终完整。
3. **天象与历法**：可配置夜空、月相、大月亮视觉效果；凶月与"神怒"历法表；季节历。
4. **图片管理**：批量导入用户绘制的地貌图片，与区域关联，带完整元数据与版本。
5. **导出**：带图例、方向、比例尺、年代、方法说明的专题图（PNG、SVG）；科学数据（GeoJSON、GeoTIFF、NetCDF/Zarr）；区域资料卡与世界设定报告。
6. **备份与迁移**：一键备份主世界与设定；磁盘占用页面，分别统计程序、第三方数据、世界快照、可重建缓存、用户图片；清理缓存不得删除用户数据。
7. 渲染效果、性能与长期可维护性的提升。

## 验收要点

- 导出的地图达到可用于设定集的质量，经用户确认。
- 注记与科学数据互不干扰。
- 备份可以在另一台电脑上完整恢复。
