# data/

| 目录 | 内容 | 是否进 Git |
|---|---|---|
| `earth_reference/` | 地球基准：指标结果 JSON、区域参照图集 | 小文件进；`raw/`（下载的原始数据）不进 |
| `external_manifests/` | 外部数据的来源、版本、日期、许可证记录 | 进 |
| `worlds/` | 生成的世界 | 参数和摘要进；大型栅格、帧序列、缓存不进 |

大型数据（`.nc`、`.zarr`、`.tif`、`.npy` 等）默认不进 Git，见 `.gitignore`。需要长期保留的大型结果（例如选定的主世界）单独打包或使用 Git LFS，事先征求用户意见。
