# 当前构造问题的经典对应与试验路线

日期：2026-10-27。接续U36-S1及用户关于方法能力边界的追问。本文归档对话中的方法判断；不是已完成的新求解器选型或修复结果。

## 问题对应

| 当前现象 | 经典问题 | 推荐处理 |
|---|---|---|
| 裂谷空隙填入整柱陆壳，原陆壳未相应变薄 | 有限变形、移动控制体与守恒输运 | 联合处理面积、厚度、体积及来源；新占面积应来自原材料展开，岩浆新增另记 |
| 65km齐顶、低盆地被吞、高山位置偏低 | 非均质材料的大陆变形、重力扩展及屈服 | 将材料分配与防止过厚拆开；有限速率转移须守恒，不能以逐圈填满代替力学 |
| B5难以形成连续低谷 | 断层盆地、岩石圈挠曲、热沉降与沉积 | 基底位移、地壳结构、沉积及载荷分别记录，防止用整柱减薄代替所有沉降 |
| 参数反复调整却回不到终图 | 受约束逆问题与系统辨识 | 先区分模型表达不足与参数不当；用少量有界历史参数、多项区域约束及敏感性校正 |
| 域扩大使走廊下降约402m | 域截断与边界条件误差 | 使用真实邻区交换或充分缓冲，分别验证域、步长和格网；开放边界仍须记通量 |
| 实体存在但输出消失、补洞改变海峡 | 重映射、欠分辨率与拓扑保持 | 区分材料量、连续变量、类别与连通关系，守恒映射不自动保证窄海峡 |
| 单个模块过关，耦合后材料反复泵厚 | 过程耦合及算子分裂误差 | 共同库存、明确过程接口、活动时间积分，验证完整循环及步长依赖 |

终图仍是设计约束。反推只寻找一组可正向实现目标的相容历史，不反放不可逆过程，也不声称恢复唯一历史。优化器不能补偿缺失的状态或过程。

## U36-S1的证据边界

已验证：在合成域、同一Landlab模型中，强区能减少低地接受侧向材料；方向性能改变分配。尚未验证：真实B6/PL8/M3f或B5改善。

旧规则在合成盆地也保持约453m，本试验未复现真实B6被填高的失败。定向走廊约93%的净增量来自预设直接供给；扩大域后侧向净输入由约+16.65万km³变成−32.36万km³。因此不能把走廊高程当成已证实的北向输送或绕流。统一截断会造平台，取消截断对照又出现约96.55km厚地壳，合理替代机制仍缺。

## 实施顺序与本次开始范围

用户2026-10-27原话：“提交并推送，然后开始尝试”（转录自对话）。

1. 首先处理最小范围的裂谷面积—厚度—体积关系，在真实历史和实际填充位置比较。保留刚性运动骨架；新增被覆盖面积须从既有陆壳材料展开，源、目标一起更新厚度和转移量，不能只更改预算名称。
2. 变形与来源底座初步成立后，分别用真实B6—PL8—M3f和B5检验材料分配、限厚、基底位移及载荷关系，不继续扩展无实际区域输入的玩具域。
3. 表达能力具备后再校正历史参数，并保留全球海陆、山系、物质来源和海峡的代价。

第一轮可采用现有单元上的守恒面积展开候选，先验证是否能替代整柱新增；它不等同完整有限应变张量、应力或变形网络求解。源区和展开分配近似必须明示为procedural_constrained，未确认的物理来源不得通过改名消失。若覆盖、材料或解析能力不足，应记为未解决，并展示真实地图后果。默认世界和验收指标保持既定版本，候选不自动采用。

## 核对的成熟框架

- [pyGPlates变形网络、地壳厚度与沉降](https://www.gplates.org/docs/pygplates/sample-code/pygplates_reconstruct_crustal_thickness_and_tectonic_subsidence)：给定运动的变形重建，可供衔接；不是唯一历史反演器。
- [England–McKenzie薄黏性板](https://academic.oup.com/gji/article/70/2/295/557795)及[修正](https://academic.oup.com/gji/article/73/2/523/716489)：大陆变形经典框架；尚未为本项目选择新实现。
- [Landlab Flexure](https://landlab.csdms.io/generated/api/landlab.components.flexure.flexure.html)与[NormalFault](https://landlab.readthedocs.io/en/latest/tutorials/normal_fault/normal_fault_component_tutorial.html)：分别提供挠曲及断层运动表达；后者不完整搬运水平材料，不能直接冒充守恒拉分盆地。
- [ESMF守恒重映射](https://earthsystemmodeling.org/regrid/)：以覆盖面积处理积分量；不自动保证地形连通。
- [SciPy有界最小二乘](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)：用于适当的参数子问题；离散接触事件可能使响应不光滑。
- [NASA验证说明](https://www.grc.nasa.gov/www/wind/valid/tutorial/verassess.html)：守恒、空间、时间及模型适用性应分别核查。
