# 物理基线（Physical Baseline）

> 行星、恒星、月亮的默认参数，时间轴规则，以及"物理天花板"。
> 默认锁定；高级设置可以解锁，但改动必须记录并说明影响。

## 1. 行星与恒星

| 参数 | 默认值 | 说明 |
|---|---|---|
| 平均半径 | 6371 km | 球面计算统一使用此值（或明确声明所用椭球） |
| 表面重力 | 9.81 m/s² | |
| 自转周期（现时代） | 约 24 h | 深时允许变化，见第 4 节 |
| 公转周期 | 约 365.25 天 | |
| 轴倾角 | 约 23.44° | 可在气候实验中做小幅变化（米兰科维奇式旋回） |
| 恒星 | 太阳型，入射通量约 1361 W/m² | |
| 大气 | 约 1 bar，N₂/O₂ 为主 | CO₂ 浓度允许在古气候实验中变化 |

## 2. 月亮

### 2.1 目标

- 现时代**视直径约为地球月亮的 1.5 倍**（高级设置可调到 1.5–1.8 倍）。
- 必须由真实的轨道参数产生，**不能只在渲染器里把月亮放大**。

### 2.2 默认候选方案

| 参数 | 默认候选 | 说明 |
|---|---|---|
| 质量、半径 | 与地球月亮相同 | |
| 半长轴 | 约 256,000 km（现今地月距离的 2/3） | 视直径约 1.5 倍 |
| 偏心率 | **0.07–0.09**（地球月亮约 0.055） | 增强近地点效应，服务"神怒" |
| 轨道倾角 | 约 5° | 产生类似 18.6 年的交点周期 |
| 自转 | 潮汐锁定 | |

推论（需在代码中实际计算并写单元测试，以下仅供核对数量级）：
- 恒星月周期按开普勒第三定律缩短为约 14.9 天，朔望月约 15.5 天。
- 主要引潮力尺度约为地球的 (3/2)³ ≈ **3.4 倍**。**这不等于各地实际潮差是 3.4 倍**。局地潮差取决于海盆几何、水深、共振和耗散，必须由潮汐模型计算。
- 近地点与远地点的引潮力之比约为 ((1+e)/(1−e))³：e = 0.055 时约 1.39，e = 0.08 时约 1.62。

也允许调整卫星的尺寸与密度，探索"视直径相同、潮汐强度不同"的方案。必须做 Roche 极限与轨道稳定性检查。

### 2.3 月亮不能做什么

大月亮影响海岸潮汐、天文历法、夜景与文化，**不能用来凭空修复大陆内部的降水**。

## 3. 潮汐与"神怒"

- 第一层：天体引潮势（由轨道参数直接计算）。
- 第二层：**主内海及其海湾的二维浅水潮汐模型**，这是核心需求，不是可选模块。必须能算出各海湾的潮差、共振周期和涨水过程。
- 验证基准：
  - 矩形海盆的固有振荡周期应符合 **Merian 公式** T = 2L / √(gh)（单节点湖震）或 4L/√(gh)（一端开口的海湾）；
  - 共振放大应能在一个类似芬迪湾的测试海湾中重现。
- "神怒"事件 = 近地点 + 朔望 + 风暴增水（+ 可能的湖震）的叠加。需要能给出这类事件的**重现周期**，供世界观的天文历法使用。

## 4. 时间轴

- 范围：**300 Ma → 0 Ma**。0 Ma 是世界观的现时代。
- 存储间隔（起始策略，不是求解器步长）：
  - 构造：0.5–2 Ma 一帧；
  - 气候关键时代：5–10 Ma 一帧，构造剧变时加密；
  - 冰期旋回：只在最后几个百万年做精细处理（服务冰川地貌）。
- 地形、水文、气候各自按其物理尺度和稳定性条件计算，不能共享一个虚假的统一步长。
- 每一帧标记 `calculated / parameterized / interpolated / visual_only`。
- **潮汐演化**：月亮越近，潮汐摩擦越强，月亮外移和行星自转减慢越快。300 Ma 的历史中，月亮轨道和日长应采用清楚标注的潮汐演化近似，不能把现时代的 24 小时和 256,000 km 原样复制到所有年代。

## 5. 物理天花板

奇景要"更险、更奇"，但在地球重力和类地壳条件下有上限。超过以下范围必须打"幻想例外"标签，并在点击面板里说明。

| 量 | 地球参考 | 本项目软上限 | 依据 |
|---|---|---|---|
| 最高山峰 | 珠峰约 8.85 km | 约 10 km | 岩石强度与地壳均衡限制山体高度，地球重力下量级约 10 km（Weisskopf, *Science*, 1975）。火星奥林帕斯山高约 22 km，是因为重力只有地球的 0.38 倍 |
| 大型高原平均高度 | 青藏高原约 4.5–5 km | 约 5.5 km | 受地壳厚度（约 70 km）与重力扩展限制 |
| 峡谷深度 | 雅鲁藏布大峡谷约 5–6 km | 约 7 km | 需要快速隆升 + 大流量河流 |
| 峡湾深度 | 松恩峡湾约 1.3 km | 约 2 km | 需要厚冰盖长期下切 |
| 海沟深度 | 马里亚纳约 11 km | 约 12 km | |
| 局地潮差 | 芬迪湾约 16 m | **由潮汐模型决定** | 大月亮使引潮力约 3.4 倍，但共振放大受耗散限制，不能简单相乘 |
| 地形坡度 | 大尺度山坡多为 30–40° 阈值坡 | 遵守阈值坡 | 局部悬崖可以更陡，但不能大面积出现 |

大洋水深应遵守**洋壳年龄—水深关系**（新洋壳浅、老洋壳深，近似与年龄平方根成正比；Parsons & Sclater, *JGR*, 1977）。

## 6. 参考坐标与单位

- 坐标：经纬度（度），经度范围 −180° 到 180°。
- 高程：米，相对海平面。
- 时间：Ma（百万年前），0 = 现时代；现时代的日历日期另行存储。
- 所有球面统计必须**按面积加权**，避免高纬度格点面积被高估。
