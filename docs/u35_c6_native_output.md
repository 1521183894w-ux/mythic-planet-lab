# U35-C6：直接原生取样的独立输出候选（2026-10-26）

本轮接续 `add960a`，按用户“怎么不继续”的指示继续推进。新增可实际导出的原生取样器、四个独立世界和六张对照图，完整标准图组29张。它改善了 C4 山脊端部的输出表达，**没有改变地壳演化、采用 C4 或更换默认 C2 世界；平顶、海口成因与 U35 的其他工作仍未完成。**

## 实际变化

原管线是“移动地壳单元 → 固定 L7 节点 → 输出像元”，新候选直接按各板块的旋转参照格网查询输出像元。覆盖重叠时沿用陆壳、厚度、年龄的优先级；无原生覆盖处明确回退既有固定视图，不生成新地壳。海沟显示项、动力高程、已有火山岛掩膜全部保留，比较不再混用缺少海沟项的原生高程。

完整状态捕获后，直接查询全部 **163842 个固定节点**，与引擎现有覆盖选择逐项相同，其中 **29个节点双方均为无原生覆盖**。覆盖选择一致不表示球面镶嵌无缝。重跑与 C5 的 **352 个保存数组、事件、体积预算完全相同**；模拟约403秒，包含保存/汇总的命令总用时441秒。输出取样器不进入碰撞、提交或物理更新。

## 回退、填洞与水路分别记账

`tect_sampling_status` 为位掩膜：

- 位1：该位置没有原生单元覆盖，回退固定节点值；这是 `interpolated` 表示约定，不是实体地壳证据。
- 位2：沿用旧视图填洞，只在同一原始宿主上应用，不把相邻填洞的陆地盖到另一真实宿主上。
- 位4：既有火山岛掩膜将水下像元显示为小岛，与原管线相同；它没有修改基底单元。

主候选1024×512的无覆盖回退约305.5万km²（精确值见JSON），沿用填洞约2.07万km²。当前完整原始状态到快照有 **26个节点**执行视图填洞。C5窗口中两处未解释的分类差异（节点49591、100989）均在这26个节点中；本轮实际读取填洞前后状态，已将该差异定位到显示处方，而不是把重建误差当作地壳变化。

四个候选中，剔除西口年轻洋壳后，内海到外洋的4连通仍断开；剔除回退像元则仍连通。因而本轮没有解决年轻填隙单元的成因，不能把新输出的水路连通说成海口地质已闭合。

停用视图填洞时，A算法在约 **16°E、46.3°N** 额外识别1个与外洋标签相邻的接口；沿用填洞时只有西口接口。**封住西口窗口后，两种策略、两种输出间距的4/8水路均不通外洋**。这说明接口计数与真实全程水路不是同一证据，不能直接把这个单像元接口称为第二条真实海峡。本轮仅重用现有算法定位接口，没有改定义、阈值或隐藏计数；图44与JSON保存对照。

## 全球代价与保留问题

直接取样是全球输出规则变化。1024×512沿用填洞候选相对旧管线的海陆分类改变约 **406.6万km²**，其中本轮西口统计窗口（30°W–5°W、33–40°N）外约397.9万km²；某些边界像元在海沟与高地间换宿主，最大高差约10.68 km，不能把这些值当作真实瞬时隆升或沉降。

原生取样更直接反映现有粗单元，不表示全球地貌已经变好。标准图组：主大陆B项9/9、极地陆块9/9，远方大陆仍8/9；其100 km海湾指数约 **0.012576 < 0.013452**，且比C4的约0.012851略低。必要指标仍未全过，不能靠A层通过或局部更连续就整体采用。

M31平顶、全宽山弧和两端过渡，R17实体与海口年轻单元，东方同高台面、r2具体湾岬成因、东南岛体层次、B5拉分洼地等均保留。新候选仍包含插值回退和旧视图填洞的假设。默认终图、运动、质量配置和正式数据没有变化。
