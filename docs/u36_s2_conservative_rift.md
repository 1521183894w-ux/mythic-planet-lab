# U36-S2：真实裂谷路径的守恒面积展开试验

日期：2026-10-27。前置路线已按用户“提交并推送，然后开始尝试”归档并推送到 `3a2b371`。本轮随后实际改代码、跑两案300→0Ma、出图及测试；不是只写方案。**候选未采用，默认仍C2，U35及阶段1未收尾。**

## 结论与能力边界

守恒面积展开可以替换旧 `rift_fill` 的无来源整柱新增：新柱有真实扣除的供体，供受体体积闭合。它没有解决形变几何、盆地、热沉降或应力分配；直接放进现有刚性单元缝隙规则后，B5反而变成过深、连通大洋的槽。**保留守恒算子作为后续底座，不采用这套供体范围与全局应用结果。**

| 问题 | 本轮结果 |
|---|---|
| 裂谷新陆壳无材料来源 | 候选对应路径无整柱新增；内部转移60,465,696.879km³，源柱同步变薄 |
| 新增面积与厚度的库存关系 | 在固定单元表上闭合；不证明空间无缝覆盖或连续有限变形正确 |
| B5谷底与形态 | 从过高变为过深贯通槽；未实现约−400m目标，不可叫修复完成 |
| B6、PL8与M3f | 仍未解决；B6/PL8固定输出中位4945m，M3f走廊P90由509降至403m |
| 小洞缺额来源 | 未解决且增加：624,731→1,195,152km³ |
| 薄陆壳与破裂转换 | 出现大范围极薄陆壳，却没有地幔出露、破裂或洋化的状态转换 |
| 年龄/省份 | 新单元继承最大体积供体代表值；完整运输边可查，但不是组分混合求解 |

## 实际方法与可复算条件

新增 `Params.rift_area_conservative=False`，默认路径原样保留。候选只把它设为True；物理配置以C11持续减薄案为对照，配置语义只差这一个布尔项。既有张开、活动时间、最大宽度判据保留；旧剖面厚度不再指定新柱厚度。

对新目标j，将其面积A_j按“同一板块对的陆壳、现有12近邻、源面积/软化距离平方”分给源d，记为E_jd，满足Σ_d E_jd=A_j。源原面积A_d、原厚度H_d，采用：

```text
ΔA_d = Σ_j E_jd
β_d = 1 + ΔA_d/A_d
H'_d = H_d/β_d
H'_j = Σ_d(E_jd H'_d)/A_j
Σ_d A_d H'_d + Σ_j A_j H'_j = Σ_d A_d H_d
```

所有目标同时分摊，共享源只扣一份库存，无目标顺序争抢。不设最低厚度，不以新增补缺额；没有供体或正体积则报错。新柱的最近改造为裂谷，形成时间不再冒充本次生成：取最大体积供体的年龄、省份及形成时间。运输边记录源UID、目标UID、面积和体积，方便追溯；不是岩浆成分追踪。

**method_class：**历史/终图 `user_override`，面积分配与地壳规则 `procedural_constrained`，既有Airy/GDH1高程 `parameterized_physics`，观察/输出 `interpolated`。面积km²，厚度km，体积km³，高程m，时间Ma。没有新求解器或新依赖；SciPy稀疏矩阵只做分配矩阵计算。这里的β是本次面积分配因子，**不是**已恢复的连续应变张量或300Ma累计应变。方法路线与框架参考见 [经典问题对应与修复路线](classical_problems_and_repair_route.md)。

运行L7共163842节点，平均节点间距约60.16km；输出1024×512。B5原生查询步距0.025°、轴线421点，只提高观察采样密度。没有气候、河流或沉积求解，不将海底自动当湖底。

## 实测结果：守恒改善与地图代价同时列出

共33次提交执行面积展开，产生1144个目标单元，累计覆盖新增面积3,492,192.705km²（出生面积累计，不是现今净新增陆地）。4729条供体记录可以重复包含同一单元，单次β为1.0187–3.2760，中位1.1281。目标出生厚度3.355–43.192km、中位16.992km；本轮无厚度下限裁剪。逐次供受体体积最大绝对残差4.66×10⁻¹⁰km³，累积两总量之差为0（浮点加总意义）。

`rift_transferred`是内部运输，**不得计入净物质源**。`rift_fill`在候选中没有发生；其余物质源未消失。现今陆壳总体积约60.368→59.381亿km³，这一差值还含弧增生、剥蚀、陆内减薄等反馈，不应全部简单解释为“原来多出的裂谷体积”。

| 同口径观察 | 对照C11复跑 | 守恒候选 |
|---|---:|---:|
| 裂谷整柱显式新增/km³ | 102,024,121.655 | 0 |
| 小洞显式缺额/km³ | 624,731.135 | 1,195,151.510 |
| 现今标作陆壳且厚<7km面积/km² | 0 | 935,553.738 |
| 现今标作陆壳且厚<15km面积/km² | 112,268.220 | 2,770,355.688 |
| 65km厚度上限上的陆壳面积/km² | 3,837,633.762 | 3,811,300.532 |
| 终图海陆IoU（既有摘要精度） | 95.2% | 94.0% |
| B5定位点原生高程/m | +1024.115 | −1281.026 |
| B5实际设计轮廓原生中位/m | +857.353 | −2702.737 |
| 同一轮廓原生低于海面面积占比 | 0.565% | 94.582% |
| B5观察轴原生范围/m | +456.845～+1139.507 | −4579.590～−952.027 |

7/15km是观察分组，不是新验收阈值。极薄大陆地壳可以存在；问题在于本模型没有描述其破裂、地幔出露、热结构与沉积载荷，不能凭“还是CONT”就宣布这些广域深槽地质合理。

B5设计轮廓约30,080.926km²，两案原生覆盖率都100%。候选固定输出定位像元在四/八邻接均连通全球最大水体；这证明当前输出是开放水道的一部分，不能称为封闭死海式盆地，也未求解湖面。固定输出区域中位为−1672m，与原生轮廓−2703m不是同一取样口径，不能混用。

B5定位点仍为UID52985，25/20/15Ma分别直接转出39,000.822/10,003.849/3,236.389km³。这只是本算子的直接材料账；完整高程变化还包含全历史的碰撞、侧向流动等耦合反馈，未声称唯一局部成因。

全球海陆改变约3,099,610km²，高程变化>100m涉及约9,505,380km²；最大降幅约7377m。差值图色带±1500m，超出范围饱和，未隐去极值。候选不能因A层通过而采用。
