# U36-S3：网格空隙、法向张开与物理变形带宽度

日期：2026-10-27。接续用户要求：“继续下一步优先用解析张开、纯走滑和刚体旋转验证：**当前网格缝隙中，哪些是真实伸展，应由多宽的地壳共同承担。** 这层关系成立后，再接入 B5 的断层位移、盆地门槛与沉降过程”（转录自对话）。

本轮有实际运行、图和数据，属于方法检查点。没有新世界候选被采用，默认仍C2，U35与阶段1均未收尾。

## 本轮得到的答案

1. **现有空隙和旧正张开判据均不能直接当成真实地壳伸展。** 光滑连续边界纯走滑时，解析法向张开为零，离散刚性单元仍出现缝隙；旧最近点连线把其中一部分当作裂谷。其后即使每次转移体积闭合，也会凭空产生减薄。
2. **独立边界法向可以排除这组纯走滑的旧正候选，但实际世界的法向仍不完备。** 三个物理观察尺度的边缘拟合，只能给出支持度。真实历史旧候选中约33.0%的累计出生面积有一致张开支持，约66.2%未定；不能称为33%已经证实真实、其余67%都是假的。
3. **两侧刚体速度与开口量不能唯一确定应变带宽度。** 当前12近邻只是网格支撑，不能替代物理带宽。需要独立定义两侧材料边界、参考宽度和带内速度，再积分材料面积变化。B5后续接入条件尚未满足。

## 解析关系与试验范围

没有安装新依赖，没有选择新求解器。新增模块为独立诊断，不接入正式Engine：

- `packages/tectonics/deformation_kinematics.py`：给定法向的速度分解、有限变形恒等式与给定带宽的时间积分。
- `packages/tectonics/gap_diagnostics.py`：只读重建现有commit裂谷候选；独立拟合两侧材料边缘，不修改预算或地壳。
- 三份 `scripts/design_gap_*.py`：合成试验、真实控制旁观、图与报表。

在同一球面位置x，给定由A侧指向B侧的切平面法向n：

```text
v_rel = R × ((ω_B − ω_A) × x)
v_n   = v_rel · n              # 正值为张开，负值为闭合
v_t   = v_rel · (x × n)        # 有符号走滑
```

旧判据用两侧最近单元的连线代替n。连线有沿边界偏移时，v_t可以污染旧正张开判据。解析反例及全局旋转下的不变性已实际测试。**纯走滑有剪切应变，面积伸展为零；不能写成“完全无应变”。**

参考变形带宽W0为两侧共同承担的初始总宽度，沿带无散度、无物质源时：

```text
F = Q × [[1 + Δ/W0, 0], [S/W0, 1]]
J = det(F) = (W0 + Δ)/W0
H = H0/J
```

Δ为法向张开，S为沿带错动，Q为整体刚体旋转。逐步更新必须使用当前宽度，再连乘增量J；不能每次都拿初始W0当本次分母。一般二维变形应跟踪完整F/J，上述一维关系只验证这一族解析场，没有代替全球应变求解。

方法标签与完整清单见 `data/worlds/design_v2/u36_s3_manifest.json`：解析运动学与给定带宽展开为procedural_constrained，实际边缘法向为interpolated，规定历史为user_override，既有高程为parameterized_physics。长度km、面积km²、体积km³、时间Myr/Ma、角速度rad/Myr；不把这些诊断标成numerical_physics。

## 三类连续真值与离散覆盖

采用两个初始互补半球，陆壳35km，节点按半球归属。三个边界相位，L5/L6/L7平均边长240.624/120.320/60.161km，共27个末态覆盖对照；相同初始几何另做27组提交间隔对照。

- 张开：两半球绕垂直于初始边界法向的轴反向旋转；赤道相对速率10km/Myr，20Myr累计200km。球面另一侧同时闭合，正开口球面月牙面积的解析真值为2R²α，α为相对旋转角，约254.84万km²。这是局部运动学开口，不代表材料已在某个已知宽度上伸展。
- 纯走滑：两侧绕半球法向反向旋转，光滑半球边界的位置不变，解析张开面积为0。离散Voronoi台阶边缘对滑时出现的空隙与重叠属于离散几何误差。
- 刚体旋转：两侧共同旋转，解析开口和材料应变均为0。

只推进旋转和commit，**未启用相互作用、碰撞、弧增厚、侵蚀或流动**。因此本试验不是完整300Ma地质演化。没有改变正式引擎的覆盖/补缝规则。

### 不能只数固定节点

三个相位的固定节点结果：

| 情景 | L5空隙面积 | L6空隙面积 | L7空隙面积 |
|---|---:|---:|---:|
| 纯走滑 | 0 | 73.82万–97.71万km² | 68.71万–87.09万km² |
| 刚体旋转 | 0 | 0 | 0 |

L5中张开、走滑均没有固定节点落进窄缝，**不是实际没有缝隙或没有开口**。为此另用不依附材料网格的全局等面积Fibonacci点积分：全部27案用相同40万查询点；相位0再用80万点核对。每个查询点覆盖面积为1275.16/637.58km²，这是积分权重，不是模型分辨率。

相位0、80万点的纯走滑离散空隙为：L5约114.51万、L6约81.87万、L7约33.92万km²；其连续真值都为0。相位0的张开离散空隙约255.41万、255.48万、254.46万km²，看似已接近总面积真值，但L7仍有约25.25万km²出现在真实开口外、约24.29万km²真实开口被错误覆盖。**总面积误差小不能证明空隙位置正确。**

40万→80万点的相位0面积差最大约3.19万km²。三个边界相位不足以证明全局收敛阶数，也没有把独立积分当成精确多边形并集。固定节点的加速覆盖与两板块穷举覆盖在这27案上无不一致节点；这排除了本组样本里的候选板块加速漏查，不能推广为所有真实接触的证明。

### 固定物理W0后的对照

给定同一200km张开，H0=35km：

| 输入W0（两侧初始总宽度） | 最终宽度 | J | 最终整柱平均厚度 |
|---|---:|---:|---:|
| 100km | 300km | 3 | 11.67km |
| 200km | 400km | 2 | 17.50km |
| 400km | 600km | 1.5 | 23.33km |

三者都是试验输入，并非反演结论。dx=40/20/10km的实际带内单元面积、dt=0.5/1/5Myr的面积因子积分（27组）与解析值一致；末步精确截到20Myr。27组独立单元多边形面积最大绝对误差1.17e−10km²，单位走向长度体积最大误差5.46e−12km²。这只证明**带宽独立给定后**的面积—厚度关系不随这些离散参数变化，不证明真实地壳该采用其中哪一个W0。
