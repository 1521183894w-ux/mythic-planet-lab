# 终图偏差的成因、修复方向与反推方法分析

日期：2026-10-27。接续[当前世界偏差报告](current_world_deviations.md)，记录对用户四个问题的分析：偏差为何产生、如何修复、终图是否不现实、为何不直接从终图反推。

本文基于既有运行结果、代码核查与参考文献。**没有运行新的地壳演化，没有证明下列修法已经奏效，也没有采用候选或宣布阶段通过。** 默认世界仍为C2，最新C11持续减薄情景仍是候选。保存本分析不代表用户已经批准某项具体结构方案。

## 一、核心判断

目前没有证据表明终图整体不现实。主要问题在于：终图反推已做了运动、部分体积和事件参数设计，但正向引擎对地壳空间分配、构造分区和盆地沉降的表达不足，不能稳定返回设计的地理格局。

“只倒推了板块位置”也不准确：已有总体地壳体积反推和少数造山事件强度估计。欠缺的是可靠的区域分配，以及以终图区域误差为反馈、受物理约束的系统校正。不能因为当前引擎做不到，就认定用户终图要求不合理。

## 二、造成偏差的成因与证据强弱

| 偏差 | 当前已知原因 | 尚未证明的部分 |
|---|---|---|
| 齐高平台；B6红层盆地、PL8较低高原被抬高 | 统一65km地壳上限，加上超厚物质向外围逐圈填充，容易将多个区域填到同一高度；规则没有充分区分刚性盆地、易变形造山带及方向性的流动阻力 | 各位置由直接碰撞、外围摊入等过程各贡献多少，尚未全部拆分；不能声称已有完整因果比例 |
| M3f高原中北部山脉偏低 | 它已被计入总体目标体积预算，但总体材料需求不保证增厚发生在该走廊；现有正向结果表明空间分配没有符合目标 | 应变分配、增厚传播、剥蚀等因素的独立贡献尚未证明，不宜简单判断为总材料不够 |
| M23远方大陆北缘山地偏低 | 已确认设计走廊内最终高程不足 | 俯冲几何、增厚速率和剥蚀各自的贡献尚未查实，不能直接套用M3f的解释 |
| B5连续低谷未形成 | 原有地壳较厚，后续碰撞与侧向流动影响抵消减薄；当前主要以整根地壳厚度推算高程，对局部断层沉降表达不足 | 新生材料、混合流动和增厚之间的完整成分贡献尚未查清，不存在已经证实的唯一原因 |
| 岸线、岛体及端部偏移 | 约60km物理网格，以及移动地壳映射、补空隙、输出取样，影响细窄地形；M31端部的一部分“缺失”已有取样显示问题的证据 | 不能把约370万km²的目标陆地损失全部归于分辨率；其中还含真实演化差异 |
| 未解释的新生陆壳 | 张开空隙中生成整柱陆壳，没有同步扣除原有陆壳体积或求解其他来源 | 可追踪账目不等于建立了可接受的地学来源；全球量不能直接归因到B5 |

### 4945m为何重复出现

现有代码的陆壳高程近似为：

`高程/m = 400 + (地壳厚度/km − 35) × 151.5`

达到65km厚度时：

`400 + (65 − 35) × 151.5 = 4945m`

因此，多个区域都接近4945m主要反映统一上限与物质分配规则，并非这些区域自然应具有同一高度。65km是当前模型规则，不是本行星的普适物理天花板。提高上限本身不能恢复盆地和山脉层次。

代码依据：[高程公式](../packages/tectonics/crust.py)、[侧向流动与超厚地壳填充](../packages/tectonics/engine.py)。本次核查位置为 `crust.py` 的 `Params`、`elevation` 与 `engine.py` 的 `_surface`、`_collapse`、裂谷填充路径。

### B5的证据边界

C11实际弯曲设计轮廓约30081km²，中位约857m、中心约1024m，仅约0.565%面积低于海面，沿设计轴最低仍约+457m。谷底目标−400m不要求整个轮廓都低于海面。不同轮廓、原生查询和固定输出统计不能混用。

现有审计没有证明全球约1.02024亿km³的裂谷整柱新增是B5偏高的唯一原因；中心也没有直接接收来自所追踪“出生时含新增宿主”的侧向流入。具体来源与通量边界见[C11来源审计](u35_c11_birth_sources.md)。

## 三、对应的修复方向

下列是待验证的工程方向，不是已经完成的功能或选定的新求解器。

1. **修正高原—盆地之间的地壳分配。** 用有方向、受构造分区约束的变形与物质转移，替代过于均匀的逐圈填充。表达造山带继续变形而旁侧刚性盆地保持较低的情形；物质去向须守恒。只提高65km上限会改变平台高度，不保证恢复区域层次。

2. **补足B5的盆地沉降表达。** 表达断层控制的沉降，处理其与地壳流动、沉积填充的关系；不能持续只加大整根地壳的减薄倍数。应先用小范围试验验证连续低谷、两侧高地与端部过渡，再做全球对照。

3. **补足张开时的面积—厚度—体积关系。** 原有陆壳拉长，应同时变薄或发生可追踪转移；若有岩浆新增则单列来源。修复整柱新增不能只将其换一个预算名称。

4. **以终图校正区域历史参数。** 调整对应的缩短范围、方向、时段和初始陆缘，使材料在正向演化中到达正确区域。同时比较山脉、盆地、海岸和预算，防止为抬高一条山而填平旁边盆地。M23应在同一修正试验中区分所缺的增厚因素，不直接往最终图上叠山。

5. **在能力与分辨率允许后做局部修正。** 保留既定的局部人工调整路线，并标 `user_override`；不能把人工修正称为引擎自然生成。细窄海峡和岛体须区分物理分辨率不足、输出取样错误及实体演化偏差。

实施应先验证这些规则能否表达目标地理关系，再做受约束的参数校正；对已有明确证据的问题推进修复，不以连续增加来源观测代替地貌改善。试验结果与必要检查可以作为同一次修正的证据，不应把每个诊断工具都扩成独立修复行动单元。方法选型仍遵守项目的成熟框架复用、许可证、Windows可用性、CPU与内存约束；本文没有完成新框架选型。

## 四、终图版本要求是否不现实

**当前没有足以否定整张终图的证据，也没有证明所有精确位置、高度和时序都可同时满足。** 应区分地理要素的合理性、全球组合自洽性与当前模型的表达能力。

- 高原旁保留低盆地有现实对照。青藏高原东缘的一项地震剖面研究报告川西高原与四川盆地平均地形分别约3874m、544m，地壳厚度约62km、43km，结构存在明显差异。这支持“不能因高原外扩就把旁侧盆地一并填成高原”的判断，但不独立证明本项目全部布局。[Wang等，2007，JGR](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2005jb003873)
- 约−400m的死海式低地有现实原型。[IUGS死海地质遗产说明](https://iugs-geoheritage.org/geoheritage_sites/the-dead-sea/)
- 一项死海盆地研究在其数据分辨率内发现，约18km以下地壳和莫霍面未随盆地形成明显改变。因此局部地面下陷不必等同整根地壳同比例变薄。这是具体研究的解释，不是所有拉分盆地的唯一成因，也不意味着它可不经验证直接移植到B5。[USGS收录的ten Brink与Flores研究，2012](https://www.usgs.gov/publications/geometry-and-subsidence-history-dead-sea-basin-a-case-fluid-induced-mid-crustal-shear)

全球组合仍应检查体积、应变、速度和时序的相容性。终图是宏观地理设计，不要求每个示意像素逐点吻合：约80km海峡在约60km物理网格上只有一两个单元，不能可靠表达。示意器还存在岛体覆盖名义山高等局限，应同时保留名义地理要求和同窗统计，不能把绘图器误差当成物理要求。

这些判断不授权修改质量指标定义或阈值；如有确切矛盾，应单独展示约束冲突、说明最小调整及代价，再由用户决定。

## 五、为何不直接从终图反推

**应该继续以终图为约束反推，这本来就是U22确定的路线。现状是落实不完整，不能说尚未采用终图反推。**

已经做过：

- 按终图划块，给定关键帧、位置和板块运动；记录见[构造方法说明](tectonics_method.md)的U23。
- 按目标高原/山系估算部分总体地壳需求，并补回可能被碰撞消耗的陆缘。
- 对少数山系设定与目标高度有关的挤压强度和活动时段。

M3f已列入 `config/design/history_v2.yaml` 中东方大高原碰撞的 `volume_balance.builds`。该预算也包含PL1、PL8及M3系列山系，所以M3f偏低不能简单解释为“忘了写这条山”。已有[初始世界脚本](../scripts/design_initial_world.py)负责总体需求及供给估计；它不能保证正向分配位置正确。

尚未做好的部分：

- 总材料需求与各区域厚度/高程分配缺少可靠连接。
- 部分目标所需过程尚不能被现有状态变量充分表达。
- 终态区域误差尚未形成系统、受物理约束的历史参数校正闭环；此前过多工作停留于解释和排查结果。

完整路线应为：

**终图主要地理约束 → 一组相容成因、初始条件和历史参数 → 正向演化 → 区域误差与预算校验 → 校正初始条件和事件 → 再正向检验。**

这不等于反向积分地壳过程，仍遵守“只倒推运动，不倒放地壳过程”。目标是找到能正向产生终图大格局的一种合理历史，不声称恢复唯一真实历史。校正也不等于每一步把高度强拉回终图后冒称自然演化。

pyGPlates官方文档支持给定运动/拓扑模型后的几何正向和反向重建，也描述应变、厚度因子与构造沉降。这说明已有成熟的运动学表达可参考，不意味着软件能仅凭终图自动求出唯一地质历史，也不代表本项目已采用其全部变形能力。[pyGPlates Primer](https://www.gplates.org/docs/pygplates/pygplates_primer)

## 六、推进边界与本分析的状态

建议保留现行终图，优先处理已识别的地壳分配、盆地沉降及新增材料来源，再将已有反推补成受约束的正向迭代。普通岸线差异按具体地理作用判断；局部人工修正保留明确方法标签。

本文将事实、因果判断和修复建议分开。没有新增运行结果、通过记录或新的剩余行动单元估计；没有修改默认世界、历史参数、终图、质量指标、独立评审报告或用户评审原文。此前各检查点严重问题是否关闭仍须有实际修复与评审证据，保存分析不构成关闭依据。
