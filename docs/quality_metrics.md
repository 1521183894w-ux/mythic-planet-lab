# 质量指标（Quality Metrics）

> 本文件定义"怎样算好"的**可计算部分**。再次强调：这些指标是必要条件，不是充分条件。评审与用户确认见 `review_protocol.md`。

---

## 0. 总原则

1. **以地球为基准，不以单一阈值为基准。** 大多数指标的目标是"落在地球的合理范围内"或"接近地球分布"，而不是"大于某个数"。
2. **同分辨率比较。** 海岸线分形维数、坡度分布等指标强烈依赖分辨率。地球基准必须用 ETOPO 2022 重采样到**与虚构世界相同的格网**，用**同一套代码**计算。
3. **指标代码集中在 `packages/metrics/`**，有单元测试。指标的定义、阈值、权重写在 `config/metrics.yaml`。修改它们必须单独提出、说明理由，并经用户同意。
4. **禁止为指标调参。** 如果某个改动让指标变好、但图看起来变差，以图为准。

指标分为四层：

| 层级 | 作用 | 不达标时 |
|---|---|---|
| A. 硬约束 | 淘汰明显不符合创作目标的种子 | 直接淘汰 |
| B. 一级质量指标 | 上一轮的核心失败点，必须单独盯紧 | 不能进入评审 |
| C. 地球对照分布 | 衡量"像不像真星球" | 扣分，评审时重点看 |
| D. 丰富度 | 衡量"险奇"和多样性 | 扣分，阶段 4 人工补充 |

---

## A. 硬约束（筛选用，不代表质量）

| 指标 | 目标 | 计算说明 |
|---|---|---|
| 海洋面积占比 | 71% ± 2% | 球面面积加权 |
| 主大陆占陆地面积 | 70–85% | 最大陆路连通区域。**宽度小于约 50 km 的单格"细线连接"不算相连**，避免伪连通 |
| 亚大陆数量 | 3–6 个 | 对主大陆做形态学分析（例如按地峡瓶颈切分），定义写进代码 |
| 主内海 | 存在且唯一，像残留洋盆 | 主大陆内部最大的半封闭海域；面积约 100 万–500 万 km²（地中海约 250 万 km²）；面积至少是第二大内部水体的 2 倍；通过 1–3 条海峡连通外洋；**至少与 2 个亚大陆接壤**（各占沿岸 ≥ 15%），**主轴长宽比 ≥ 2**（2026-10-21 经 0.7 校准后由用户同意增加，U18(c)：两个对照样本"一个亚大陆里挖出的圆海"都通过了原来的四项） |
| 主大陆纬度范围 | 北端 ≥ 62°N，南端 ≤ 30°S | 软边界，可在配置中调整 |
| 极地大陆 | 存在 | 中心纬度 ≥ 70°，面积约 500 万–1500 万 km²（南极洲约 1400 万 km²） |
| 远洋空旷度 | 存在大片无陆地海域 | 例如：存在直径 ≥ 3000 km 的圆形区域内无陆地 |

## B. 一级质量指标（必须达到地球级别）

### B1. 海岸复杂度

上一轮的核心失败是"海岸圆润、缺少半岛和群岛"。以下指标全部以地球同分辨率数据为基准。**判定方式（2026-10-21 经 0.7 尺子校准后由用户同意修改，原为"落在地球各大洲的范围内"）**：与地球**大陆级陆块本体**同类比较——地球与世界都按陆块单元（连通本体）切分，世界每个大陆级陆块的各项不低于地球亚非欧、美洲、澳大利亚、南极洲本体中的最小值（距海距离类不高于其最大值）；海岸发育系数随面积增大，只作参考；地球亚非欧本体为主大陆的评分目标。详见 `docs/metrics_definitions.md` §2 与 `reviews/stage0_calibration.md` §5 R1。

| 指标 | 说明 |
|---|---|
| 海岸线分形维数 | 盒计数法，尺度范围约 10–500 km（视分辨率调整） |
| 海岸发育系数 | 海岸线长度 ÷ 等面积圆的周长 |
| **半岛指数** | 对陆地掩膜做半径 r 的形态学开运算，被削掉的陆地面积占比。分别取 r = 50、100、200 km。数值越大，半岛越多越突出 |
| **海湾指数** | 对陆地掩膜做半径 r 的闭运算，被填充的海域面积占陆地面积之比。衡量深入内陆的海湾和内海 |
| 岛屿数量与大小分布 | 统计各面积级别的岛屿数；累积分布在双对数坐标下近似幂律（Korčak 经验律），比较斜率 |
| 大陆架面积 | 水深 0–200 m 的面积占海洋面积之比 |
| 海岸复杂度的空间分布（**只作统计，不设合格线**） | 沿海岸每 100 km 取一个 2000 km 窗口，算窗口内的海岸复杂度，看它的分布（p10/p50/p90、变异系数、较平直窗口占比）和地图。地球的海岸有的地方碎、有的地方直；随机噪声海岸处处一样碎。2026-10-21 经 0.7 校准后由用户同意增加（U18(a)）：噪声海岸世界的上述各项全部达标，只有这项统计把它和地球分开了 |

**B1 只是必要条件。** 0.7 的噪声海岸世界证明，B1 各项都能被"有复杂度、无成因"的海岸骗过。阶段 1 起，评审员还要做"海岸成因抽查"（`docs/review_protocol.md` §2.2b，U18(b)）。

### B2. 湿润与干旱

| 指标 | 说明 | 适用阶段 |
|---|---|---|
| **距海距离分布** | 陆地各点到最近海岸的距离分布；尤其是"距海超过 1000 km 的陆地占比"。这是在气候计算之前就能评估的干旱风险代理指标 | 阶段 1 起 |
| **Köppen 干旱气候（B 类）占陆地比例** | 地球约 30%（Peel 等, *HESS*, 2007）。本项目目标约 20–35% | 阶段 3 起 |
| Köppen 气候类型数量 | 出现的气候亚类数，目标接近地球 | 阶段 3 起 |
| 内流区（无出海口流域）占比 | 与地球同分辨率结果比较 | 阶段 2 起 |

## C. 地球对照分布

比较方式：计算虚构世界与地球的分布之间的距离（例如 Wasserstein 距离或 KS 统计量），并输出叠加对比图。

| 指标 | 说明 | 适用阶段 |
|---|---|---|
| 高程曲线（hypsometry） | 地球呈双峰分布（大陆台地与深海平原）。比较累积分布 | 1 |
| 海底水深—洋壳年龄关系 | 应近似符合平方根关系 | 1 |
| 山系统计 | 长度 > 1000 km 的山系数量；各山系的长度、宽度、弯曲度；**最长山系、主轴长宽比与走向、成带山系面积占比、低矮山地一级**（2026-10-21 经 0.7 校准后补充：单靠山系计数识别不出噪声斑块山）；山系与构造边界的对应关系 | 1–2 |
| 坡度分布 | 同分辨率比较 | 2 |
| 河流 Hack 定律 | 主河长度 L 与流域面积 A 的关系 L ∝ Aʰ，地球上 h 约 0.5–0.6（Hack, 1957）| 2 |
| 流域面积分布 | 最大流域的面积与数量分布 | 2 |
| 纬向温度梯度、季节振幅 | 与地球观测量级比较 | 3 |
| 降水空间结构 | 例如降水的纬向平均曲线、海陆降水对比 | 3 |

## D. 丰富度

- 依据 `archetype_library.md`，由识别程序自动检测世界中出现了哪些**奇景原型**及其数量、规模。
- 输出：已出现的原型清单、各自位置、"险奇程度"（相对地球同类的分位数）。
- 阶段 1 只能识别构造类原型；阶段 2 加入地貌与水文类；阶段 3 加入气候与冰川类。
- 按表达等级分开计数：A、B 级计入丰富度得分；C 级（叙事标注）和自创奇景单独列出，不计入得分。

---

## E. 种子评分与筛选

1. 批量生成 N 个种子（数量按算力决定，阶段 1 建议 30–100 个低分辨率种子）。
2. 硬约束淘汰。
3. 对剩余种子计算 B、C、D 层指标，按 `config/metrics.yaml` 中的权重算综合分。**权重公开、可调。**
4. 输出**联系表**（所有候选的缩略图排在一张大图上，标注分数），以及前 K 名（建议 5–8 个）的完整标准图组。
5. 前 K 名交给 `world-reviewer` 评审，再交给用户挑选。**分数只用于缩小范围，最终由用户选择。**

## F. 地球基准的建立（阶段 0 完成）

- 数据：NOAA ETOPO 2022（选用较低分辨率版本，按需下载）、Natural Earth。气候基准可在阶段 3 再引入公开的 Köppen 分类数据集。
- 重采样到项目使用的各级格网（例如 512×256、1024×512、2048×1024），分别计算 A–C 层的全部指标，存为 `data/earth_reference/baselines_<分辨率>.json`。
- 同时输出**地球区域裁剪图**（地中海、爱琴海、挪威海岸、东南亚群岛、东非裂谷等），在评审时作为同尺度对照。
- 来源、版本、下载日期、许可证写入 `data/external_manifests/`。
