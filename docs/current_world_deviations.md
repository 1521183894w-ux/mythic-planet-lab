# 当前世界为什么尚未过审：终图偏差与影响说明

后续分析：[偏差成因、修复方向、终图可行性与反推方法](final_map_causes_and_repair.md)。

日期：2026-10-27。本文回应用户“偏差到底有多少、在哪里、忽略后会怎样”。只重用既有 C2、C11 世界与独立评审，不运行新的地壳演化、不修改世界或验收阈值，不编号为新的修复行动单元。

**结论：既有重要的终图偏差，也有不依赖终图像素吻合的模型与地貌问题。大陆与主内海的大格局已经接近设计；部分山系、盆地却改变了地理角色。此前只报“几项严重、未通过”而没有逐项讲清偏差和影响，汇报不充分。**

## 1. 比较的是哪几版

- 正式默认世界仍是 **U35-C2**，尚未用后续候选替换。
- 最新候选为 **U35-C11 持续减薄（progressive）**。C11新增来源观测没有改变C10对应候选的地形；候选不等于已经采用的新世界。
- 现行终图为 `config/design/final_map_v2.yaml`，包含用户 U35 要求的西口短海峡、弧形山系和邻近海岸修订（`5d7a5a0`）。
- 另核对 2026-10-24 已认可的 v2 配置（`baf014e`）。两版配置均以当前渲染器在1024×512上重新栅格化；这不是当时PNG的逐像素复原。不能把用户后来要求的修改算成引擎偏差，也不能偷偷改目标让吻合率变高。

图组：[全球与关键区域](../figures/design/v2/deviation_report/index.html)。原始数值：[comparison.json](../data/worlds/design_v2/deviation_report/comparison.json)；全部57项高度：[CSV](../data/worlds/design_v2/deviation_report/all_feature_heights.csv)。

C11既有摘要中，引擎岸线到设计岸线的距离中位数为0，P90约57km；反向P90约39km。这说明多数岸线在当前格网上接近，也意味着仍有10%的岸线点偏差更大；57km不是最大偏移。物理网格L7约60km、赤道输出像元约39km，中位数0不能解释为真实岸线完全一致。

## 3. 真正改变地理角色的高度偏差

名义峰高、谷底高度和区域统计是不同量。山系用既有摘要的设计走廊内P90（90%的采样值不高于该值），高原/盆地用原设计多边形内中位数；目标与引擎在同一窗口比较。它们不是每条山系最高峰，也不是要求整个盆地等高。图02同窗展示了前三组关键位置。

| 要素 | 名义设计 | 终图同窗示意统计 | 正式 C2 | 最新 C11 | 当前含义 |
|---|---:|---:|---:|---:|---|
| B6 红层盆地 | 450m | 中位438m | 4945m | 4945m | 比示意中位高4507m；低盆地变成高地 |
| PL8 南方喀斯特高原 | 1400m | 中位795m | 4945m | 4945m | 比示意中位高4150m；失去与大高原相邻但较低的层次 |
| M3f 高原中北部山脉 | 5600m | P90 4700m | 509m | 509m | 设计山脊走廊明显偏低，南侧高地不能代替原位置山脉 |
| M23 远方大陆北缘山地 | 2500m | P90 2158m | 422m | 422m | 北缘山地起伏明显不足 |
| B5 死海式洼地 | 谷底−400m | 中位−2m | 中位1688m | 中位1024m | 已降低但仍偏高；不能用中位数代替谷底和连续性 |

B5另用实际弯曲设计轮廓作原生查询：目标面积约30081km²，C11中位857m、中心1024m，只有约0.565%的面积低于海面；沿设计轴最低仍约+457m，连续低谷未形成。这里的857m与上表1024m来自**实际弯曲轮廓/原生查询**和**原多边形/固定输出**两个明确口径，不能混算成进步或退步。−400m是目标谷底，不要求整个轮廓都是−400m。

**终图示意器也有已识别的表达局限。** 岛区山脉会被后绘制的岛体高度覆盖（例如M27名义4200m，示意走廊P90仅899m）；极区示意图含冰盖表面，引擎现阶段是构造地形。因此CSV保留名义值与示意统计两列，不能把这些差值全部判为引擎缺陷。没有修改设计、指标或阈值。

## 4. 为什么还不过审：并非只看终图吻合率

最新独立报告 `reviews/stage1_2026-10-27_3.md` 列出的3项严重问题是：

1. **新生陆壳的材料来源未解决。** 裂谷填充累计整柱新增约1.02024亿km³，没有相应的供体扣除或已求解的地学来源。审计能够对上账，不等于这些体积的形成过程成立。这是方法问题，不是海陆错位百分比；也没有证据证明该全球体积是B5偏高的唯一原因。
2. **B5没有形成连续目标谷地。** 这是明确的设计要素未实现，既有数值也有同窗形态证据。
3. **大面积齐高平台、直边与内部山盆层次不足。** 多个本应不同高度的要素都落在约4945m附近，与地壳厚度上限等规则有关；只看海岸轮廓发现不了。红层盆地与喀斯特高原的差异是具体例子。

前轮还提出北岸具体湾岬成因证据不足、岛形重复、M31拼接/端部等问题。最新评审对其中部分的严重等级有不同意见；来源审计未改地形，不能冒充修复了它们。**但也不应机械地把跨轮数量累加成6个同样确定、同样严重的终图偏差。** 尤其M31原先一部分“缺失”已证实是取样显示问题，候选高度也已接近。应按“实测地理偏差、形态质量判断、过程证据缺口”分别处理，不能仅凭旧标签持续阻塞。

定量方面，A层7/7；主大陆和极地大陆B项各9/9，远方大陆8/9，其海湾项约0.012851，小于既定0.013452，低约4.5%。这是一个具体未达项，不代表整个远方大陆不可用，也不准为了通过而改阈值。

完整阶段1还包含历史、岩性/成矿信息和同终图变体筛选等交付要求；本次评审材料未覆盖完整阶段。**“当前候选地貌未过审”与“完整阶段交付尚未齐备”是两件事**，不能都归咎于终图偏差。

## 5. 如果接受这些差异，会付出什么代价

以下“地图上已发生”的后果可由现有结果确认；气候、水文、生物与矿产的后果尚未实际模拟，是对后续依赖关系的判断。

| 偏差/问题 | 现在已经发生的影响 | 若保留，后续可能影响 |
|---|---|---|
| B6盆地、PL8低高原被约4.9km高地覆盖 | 原定低盆地与较低台地的地理角色消失 | 河流流向与汇水区、盆地沉积、定居农业区和湿热喀斯特设想都要跟着重设；气候影响量待模拟 |
| M3f、M23山地显著偏低 | 原定位置的高山屏障不足 | 雨影、迎风降水和分水岭位置可能改变；不能给出尚未运行的降雨变化百分比 |
| B5没有连续低谷 | 死海式洼地与谷地走廊没有实现 | 闭流盐湖、蒸发岩与谷地交通设定失去地形前提；并非单纯少一个地名 |
| 海陆边缘/岛弧局部差异 | 一些原定岛体、岬角、水道的面积或位置变化 | 可能改变陆桥、航道和生态隔离；总体重合度不能保证狭窄海峡正确，需按关键位置判断 |
| 齐高平台与重复岛形 | 大区域缺少山脉—高原—盆地之间的层次 | 后续侵蚀可以产生河谷，却不能保证自动恢复几百公里尺度的目标构造格局；继续依赖会放大返工 |
| 未解释的新生陆壳 | 地壳库存、厚度与过程解释的基础有缺口 | 其上的地形与历史/成矿归因可信度受限；视觉满意也不能称为来源已闭合 |

**可以讨论接受的是**：不破坏主要地理角色的岸线小偏移、局部高度差或合理自然变体。**我建议先修的是**：B6/PL8/M3f等大尺度山盆错位、B5连续低谷、齐高平台及未解释陆壳来源。这些不能用“总体95%吻合”带过。M31高度已经接近，下一步只应针对仍有证据的具体形状与成因问题，不再泛称整条山系失败。

目前没有唯一可合理概括全世界偏差的数字。已完成的是把海陆、57项高度与关键形态/方法问题拆开列清；尚未量化的湾岬过程证据与岛形问题也明确标出，不能虚构“偏差百分比”。本报告不请求用户通过，也不开始新的引擎结构调整。
