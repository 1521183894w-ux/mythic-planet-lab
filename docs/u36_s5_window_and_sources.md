## 同一轨迹上的四项核对

保留S4已登记的G8中段、200km参考总宽度、同一C/D旋转历史与35Ma材料位置。以432个原审计三角形中心为材料中心，各用半径1km的小球面斑块跟踪局部面积J；速度在同一轨迹位置作0.1km球面中心差分。长度为km、速度为km/Myr、散度为1/Myr，框架1/s按365.25天/年换算；dt=0.25Myr、短速度窗口0.01Myr。

比较的量为：框架β、框架面积应变率积分、同API速度的过去1Myr散度积分、同API短窗口散度积分，以及小斑块的几何logJ。逐材料点分解：

`log(β/J) = (logβ−∫D) + (∫D−∫div过去) + (∫div过去−∫div短窗) + (∫div短窗−logJ)`。

这条和式是代数分解，其闭合本身不证明物理正确。独立证据是各API/几何量的实际数值比较及已知球面速度场测试，而不是把四项包装成四个真实地壳过程。

| 0Ma，全部432中心按初始面积加权 | 对数差×100 |
|---|---:|
| 总log(β/J) | −1.299210 |
| 标量与框架应变率时间积分 | +0.000130 |
| 框架应变率与同窗口独立速度梯度 | +0.105462 |
| 过去1Myr与短窗口速度散度 | −1.380481 |
| 短窗口散度积分与材料面积 | −0.024322 |

35→34Ma首1Myr已经积累约−1.329%的局部中位对数差；框架应变率与过去1Myr速度散度均从接近0开始，而前向短窗口速度已经张开。官方接口说明应变率固定用1Myr速度差；点运动则可使用更短阶段旋转。因此减小材料积分dt不等于缩小框架应变率的速度窗口，解释了S4时间步细化后残差仍在。

框架β与框架应变率积分在本轮dt=0.25Myr下的局部对数差最大约1.62e−6；并没有证据将百分之一差异主要归因于β自身时间积分。空间梯度仍有不同符号的局部误差，不能把全部残差只归于时间窗口。

对同一批**原S4材料单元**，以短窗口散度积分构成诊断性面积因子，已知厚度区体积残差1.289866%→0.023875%。没有用该诊断覆盖框架β或写回全球厚度；它支持“窗口不匹配是本段主要原因”，不等于真实材料厚度已得到独立物理验证。

## 独立对照与不能推广的范围

- 全部432中心的正式时间序列141时点；另取27中心作dt=0.5/0.25/0.125Myr、斑块半径1/0.1km的6案，以及空间差分距离1/0.1/0.01km的3案。缩小斑块和dt未消除原β/J偏差，差分距离变化对短窗积分/面积误差影响很小。它们是观察密度，不是更高地壳分辨率。
- 用明确覆盖0–50Ma的旋转历史，比较恒速已持续、35Ma突启、35→33Ma两级启动；没有利用“模型在起始时刻以前缺旋转”制造对照。旋转文件每1Myr一个关键帧，所谓ramp实际为35→34Ma的25%速率、34→33Ma的75%、33Ma以后满速，**不是连续光滑加速度求解**。恒速局部中位log(β/J)末态约+0.1614%，突启约−2.3009%，两级启动约−2.2719%。初始总位移不同，不把它们当作同一最终运动下的调参选优。
- **两级启动还保留约−1.006%的局部中位“短窗口速度积分−位置面积”对数差**，明显大于真实参考段的该项。图87已列出全部四项，不能只展示时间滞后，不能把真实段约0.024%的诊断结果推广到所有时变网络。
- 本轮尚未定位该时变差异的具体点运动/速度插值口径，也没有把短窗口审计发展为新的地壳求解器。恒速/突启的对应剩余项约−0.0731%，同样没有写成严格零。
