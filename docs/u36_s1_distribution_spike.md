# U36-S1：地壳空间分配方法小试

日期：2026-10-27。接续[偏差成因与修复分析](final_map_causes_and_repair.md)。

本检查点有五张合成试验图、真实运行数据和独立评审材料。它验证分配方法的行为，**没有修复真实世界的B6、PL8、M3f或B5**；默认仍为C2，C11仍为候选。阶段1未通过。

## 1. 为什么先做这一小试

此前已确认统一65km上限与逐圈填充能产生4945m平台，但不能仅凭这一点给真实世界各处的偏差分配因果比例。本轮把“是否硬截断”“是否区分强盆地”“是否具有方向性”分别作控制组，用同一初始柱和同一材料供给比较，不调整终图或验收指标。

代码在 `spikes/stage1_distribution/`，不接入正式引擎。合成图采用局部直角坐标，**不对应真实世界的经纬度，也不是终图修复后的地图**。几何和供给没有随机噪声。

## 2. 方法与科学边界

复用已装好的 **Landlab 2.10.1 / LinearDiffuser**，未安装或升级依赖。它提供显式有限体积扩散组件，可以接受链路上的空间系数；本轮将状态量解释为地壳厚度，复用它的数学计算能力，**不把坡面扩散组件改称下地壳动力学求解器**。

2026-10-27核查：上游最新发行版为v2.11.0（2026-08-31）；仓库最新提交日期为2026-10-26，项目仍有维护；许可证MIT。本机Windows实际导入并完整运行了现有2.10.1。留用已装版本以保持两机环境一致，不因小试改锁文件。[上游发行版](https://github.com/landlab/landlab/releases/tag/v2.11.0)、[仓库与许可证](https://github.com/landlab/landlab)、[组件官方文档](https://landlab.csdms.io/generated/api/landlab.components.diffusion.diffusion.html)。

强盆地阻碍侧向变形、有利于保留高原旁低地的设想参考Clark与Royden（2000）；这只是本轮设置材料差异的依据，**不是本星球黏度反演或唯一成因**。采用的绝对扩散系数、黏度对比和方向比均未经真实区域校准。[论文摘要](https://pubs.geoscienceworld.org/gsa/geology/article-abstract/28/8/703/191881/Topographic-ooze-Building-the-eastern-margin-of)。

| 图层/量 | method_class | 说明 |
|---|---|---|
| 合成结构、方向、外部供给 | user_override | 继承强盆地轮廓与试验输入；不设最终高程目标 |
| 厚度分配 | procedural_constrained | 扩散类比；方法u36-s1-v1，非热力学或应力求解 |
| 厚度换算高程 | parameterized_physics | 沿用35km对应400m、每km增厚抬升151.5m的Airy近似 |
| 颜色、结构检查框 | visual_only | 检查框不是自然生成的构造或海岸 |

主域2400×2000km，有效面积480万km²；40km等面积格网，40Myr，外步长0.25Myr，Landlab内部按稳定条件细分。边界关闭，无剥蚀、沉积、温度、黏塑性、应力或板块运动。输入是固定高斯形供给，未由真实碰撞历史推算。

盆地外是均质弱背景，方向方案在全域取y向K=12000、x向K=3000km²/Myr，盆地核心的相对流动性降低1000倍，跨界链路用调和均值。紫框仅为北侧检查走廊，**不是另行指定的一条局部高流动性弱带**。

累计输入2591.499万km³，与假设的外部供给库等量扣减。这个库只是合成试验的明确边界账本，不证明真实碰撞供给合理，也不能用于关闭C11的rift_fill材料来源问题。报表将分区内的直接供给和净侧向输入分列，后者可为负，不冒充成分示踪。

## 3. 实际运行结果

[五图画廊](../figures/design/v2/distribution_spike/index.html)；[原始报表](../data/worlds/design_v2/distribution_spike/report.json)。

| 方案 | 盆地核心中位/m | 北向走廊中位/m | 最高诊断高程/m |
|---|---:|---:|---:|
| 原规则：扩散300 + 65km逐圈填充 | 453 | 1993 | 4945 |
| 原规则只取消65km截断 | 453 | 1978 | 9725 |
| Landlab均质扩散，K=12000 | 1157 | 1566 | 2348 |
| 同K，加入强盆地分区 | 454 | 1690 | 2590 |
| 强盆地加方向性 | 454 | 2262 | 3523 |

原规则两组通过四邻接等面积图适配，直接调用已有`Engine._surface/_collapse`，没有重写逐圈填充。**这不是C11的全球复跑**。原规则组在61.12万km²上达到65km统一上限；取消上限会出现96.55km厚地壳，不可作为修法。该合成几何中，原规则并未把盆地核心填高，不能称其复现了真实B6的偏差。

Landlab三个主控制组的材料输入、初始状态和K一致，逐步只改变材料分区和方向。其结果支持“材料差异可以保留相邻低地，方向性可以改变供给去向”的方法判断。原规则与Landlab之间同时改变K、阈值和分配机制，不能把两者差异全部归因于结构分区。

五组主对照、12组K/黏度对比敏感性、四组网格/步长/域大小对照均实际运行。全部体积闭合误差绝对值最大约3.51×10⁻⁷km³，最终完整出图运行8.36s。未测内存峰值，不能据此宣布全球性能预算已验证。

### 细化与边界：仍有明显限制

- 外步长0.25→0.125Myr：盆地中位变化不足0.001m，走廊约0.045m，最高点约14.2m。
- 网格40→20km、步长同为0.125Myr：盆地中位约差0.36m，走廊约差39.2m，最高点约差3.49m。两网格有效面积与总供给一致；结构检查窗仍有离散取样差异。
- **域长宽各加倍**、网格40km、步长0.125Myr，且原窗初始状态、源区支持和分区直接供给严格相同：走廊中位2261.56→1859.57m，下降约402m；最高3536.97→3367.95m。小域闭边界会积料，不能称结果已经与域大小无关，也不能直接用2262m去校正M3f。盆地保持约453m这一关系对本次域变化较稳定。

图05同时展示这些对照。没有把“曲线看着重合”当作完整收敛证明。12组敏感性结果全部保留，没有据验收评分挑一组后丢弃其他结果。

## 4. 世界状态参照与验证

按评审流程，从既有C11持续候选NC重新运行标准图管线，输出29张标准图、同尺度地球区域对照、同窗构造图与指标：[参照画廊](../figures/stage1/u36_s1_reference_c11/index.html)。

实际耗时59s。剔除计时字段后，本次世界指标与已有C11逐项相同，B判定也相同：A层7/7；主大陆9/9、极地大陆9/9、远方大陆8/9，海湾指数@100km=0.01285125，仍低于0.01345213。本轮世界地形没有改善，不因小试把旧问题关闭。

相关测试 **47项通过（23.74s）**，覆盖供给库/域内体积平衡、原规则上限、无源最大值原理、材料/方向退化控制组、非整数最后步长、闭边界、同域同输入细化、扩大域源区不变及参数拒绝，并回归原引擎相关测试。Landlab在NumPy2.5.4下有8条`where without out`排序警告，未修改依赖或屏蔽警告；本轮不宣称全套测试通过。

保护文件前后SHA256一致：正式引擎、地壳定义、终图、历史配置、质量指标配置与默认forward摘要。原有未跟踪的`.codex/`和`scripts/design_template.py`未纳入提交。

## 5. 评审与下一步

独立评审报告：[2026-10-27第四次](../reviews/stage1_2026-10-27_4.md)。评审员实际逐张查看34张图，列严重1项（真实世界长条齐高高地）和一般6项；建议作为方法试验检查点提交，不建议作为真实世界已改善或阶段验收。已在报告末尾追加开发者回应，保留所有未解决问题。评审正文写入曾因用量限制中断，已按评审员提供的原稿逐字恢复并核对7486字符；没有用开发者意见补写独立结论。

下一步应以真实B6—PL8—M3f的材料省份、碰撞供给和移动地壳为输入，检验受结构约束的分配；先作短时段、较大范围的过程对照，同时处理有限速率转移与统一厚度截断的相容性。当前小试不能直接替换全球规则；不应继续用更多来源观测代替真实地貌改善，也不能用更细网格掩盖地壳来源和盆地沉降的缺项。
