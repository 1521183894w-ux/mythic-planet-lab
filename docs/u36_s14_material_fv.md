# U36-S14：曲边移动材料体积账与平均厚度小试

日期：2026-10-28；基线6be2d4d；接续用户“请继续”。本轮全部计算和新增文件在D盘既有工作树；复用现有环境，无安装/下载。默认C2，未接全球/B5，阶段1未通过。

平均厚度方案可以让移动材料自身的体积账闭合，却不自动优于中心取样的局部厚度。四个反例的1/4/16真实细分表明场误差下降；这与“体积账近零”是不同证据。当前方案只是零相对边界通量的材料账原型，没有原生网格重映射或完整地壳耦合。

## 方法和参照

复用S11相同归档连接、35→0Ma的140个0.25Myr步长、两板块SLERP映射与200km假设带宽，不改来源域、初始厚度或运动场。原材料单元有向方向只在起点统一；所有边界采样点此后独立随材料移动，非每步重新拉直。

移动材料边界假设没有相对物质通量，恒密度柱体积V=面积A×平均厚度H。按积分守恒更新：

H_new = H_old × A_old / A_new。

A采用独立移动的曲边点围成的有向球面面积。更新逐单元进行，不对UID或全域做归一化；每个子单元保留自己的初始库存。账面闭合是这个更新公式的设计性质，不能作为独立精度或三维质量守恒证明。初始时使用原球面三角形解析面积，此后使用跟踪的曲边几何。

有限体积中单元平均量与点值的区别见[LeVeque 2011课程讲义，第2–3页](https://faculty.washington.edu/rjl/classes/am574w2011/slides/am574lecture5.pdf)。本轮没有安装或运行Clawpack，也没有宣称实现通用有限体积、Riemann通量或应力求解器。

独立内部参照为同一指定离散映射的连续性解H_ref=H0/J；J在独立Gauss节点上逐点累计。以初始球面面积权重w计算当前面积元wJ，不将权重归一化。主要场误差定义为：

E_L1 = Σ wJ |H_mean − H_ref| / Σ A0 H0。

它是本轮数值诊断，未更改quality_metrics中的世界质量定义或阈值。中心取样使用同一子单元/相同内部节点作比较；独立面积权重下的体积差ΣwJ H_mean−V0另列。后者检验几何和内部J积分的一致，不是独立物理真值；也不把H0/J×J的恒等式当守恒验证。

每个单元另跑一档减半边界采样的厚度账，保留边界选择敏感性。内部多档Gauss求积保留非单调差异，不把最高两档之差称为严格误差界。
